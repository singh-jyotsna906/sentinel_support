# Fixtures

This directory contains all required fixture data for the Sentinel Support assignment.

- customers.json
- cards.json
- accounts.json
- transactions.json (≥ 200k rows; use transactions_generator.js for ≥ 1M)
- alerts.json
- kb_docs.json
- policies.json
- chargebacks.json
- devices.json
- evals/*.json (acceptance/golden cases)

To generate a large transactions file, use the provided `transactions_generator.js` script.
